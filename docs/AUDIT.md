# Revision audit

This release supersedes the first project's fiscal-year split. We revisited the full run after detecting that fiscal year is not the publication date: the first release admitted 115 of 885 training outcomes after the earliest validation prediction, and 93 of 97 validation outcomes after the first test prediction. Those old score tables are invalid for a real-time forecast. The code now gates *labels* by the next filing's actual publication date and forecasts by the current filing's date. `reports/metrics.json` contains the four observed boundary dates for both cohorts. The revised test has already been inspected during development, so its p-value is exploratory even though the new code enforces availability.

`reports/data_quality.json` records structural checks on all 1,163 eligible rows, including uniqueness, annual target gaps, chronology, positive revenue and recomputed ratios. The 100-name source universe yields 99 panel firms: CNH has no eligible paired annual observation. `reports/filing_reconciliation.json` independently reads original HTML inline XBRL for eight fixed tickers (WMT, TGT, NKE, BBY, CAT, DE, GD, NOC), each with two annual filings and both revenue and capex. It reports candidate counts and whether each of 32 panel values matches an original context, USD unit and annual period. This sample is bounded; it does not validate all 1,163 rows.

The numerical preparation also now refuses gaps exceeding one adjacent fiscal year for lag features and records the chosen capex taxonomy tag. The sequence benchmark uses only source filings available by prediction time, repeats training with three fixed seeds and reports the chosen settings. The transformer now examines up to four chunks of each selected excerpt rather than only its first 256 tokens; `reports/transformer_embeddings.audit.json` records actual coverage. That change is a new analysis choice made after viewing previous results. The paired contrast explicitly holds the numeric residual ridge fixed as the baseline; the validation-selected strongest numerical benchmark is reported separately. Both use the exact same test IDs and labels as the text model.

Reproduction uses `python -m capalloc.reproduce` and the companion source snapshot. The input manifest checks 408 original files; `reports/metrics.json` includes the generated panel SHA-256 and runtime versions. Package code, tests, reports and the self-contained page are published in this repository. Generated raw input, panel, cached embeddings and downloaded model weights are excluded from Git; the raw input is available as a separate archive. Results must be regenerated for any new raw snapshot.
